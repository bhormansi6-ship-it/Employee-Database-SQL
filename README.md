# 👨‍💼 Employee Database SQL Project

A SQL project on a 500-record employee database using MySQL, covering table creation, joins, aggregate functions, grouping, string functions and window functions to extract workforce and department insights.

## 📌 Project Overview
This project uses a sample employee dataset to practice and demonstrate SQL skills, from basic data retrieval to advanced analytical queries on salaries, departments, job titles and managers.

## 🗃️ Database Structure
| Table | Description |
|-------|-------------|
| **employee** | 500 employee records (ID, name, email, hire date, job title, department, manager, salary) |
| **department** | Department ID and department name |

## 🔍 Concepts Covered
- **Basic Queries:** SELECT, WHERE, ORDER BY, LIMIT, DISTINCT, LIKE, BETWEEN
- **Aggregate Functions:** COUNT, SUM, AVG, MAX, MIN
- **Grouping:** GROUP BY and HAVING
- **String Functions:** UPPER, LOWER, CONCAT, LENGTH, SUBSTRING, REPLACE, TRIM, LEFT, RIGHT
- **Joins:** INNER JOIN, LEFT JOIN, CROSS JOIN, SELF JOIN
- **Conditional Logic:** CASE statements
- **Window Functions:** ROW_NUMBER(), RANK()

## 💡 Sample Analysis Questions
- Total number of employees and total salary expense
- Average salary and highest salary by job title
- Number of employees under each manager
- Department with the maximum number of employees
- Top 5 highest-paid employees with department names
- Employees earning more than their department's average salary
- Employee ranking based on salary

## 🛠️ Tools Used
- MySQL
- SQL

## 📁 How to Use
1. Download `employee_dataset_500_main_project.sql` from this repository.
2. Open it in MySQL Workbench (or any MySQL client).
3. Run the script to create the tables and insert the data.
4. Run the queries to explore the results.
